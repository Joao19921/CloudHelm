# Modelo C4 — CloudHelm

## Nível 1 — Contexto do sistema

```plantuml
@startuml CloudHelm-Context
!include https://raw.githubusercontent.com/plantuml-stdlib/C4-PlantUML/master/C4_Context.puml
LAYOUT_WITH_LEGEND()

Person(user, "Usuário", "Descreve uma demanda, compara custos e consulta recomendações")
Person(admin, "Administrador", "Aprova usuários e gerencia configurações de IA")
System(cloudhelm, "CloudHelm", "Analisa demandas de infraestrutura, estima custos e gera uma arquitetura inicial")
System_Ext(github, "GitHub OAuth", "Autenticação do usuário")
System_Ext(catalogs, "Catálogos AWS / GCP / Azure / OCI", "Preços e metadados de serviços cloud")
System_Ext(llm, "OpenAI / Gemini", "Geração opcional de briefing arquitetural")
System_Ext(frontendHosting, "GitHub Pages", "Hospedagem dos arquivos estáticos do frontend")
System_Ext(apiHosting, "Render", "Hospedagem do container FastAPI")
System_Ext(database, "Supabase Postgres", "Persistência gerenciada")

Rel(user, cloudhelm, "Usa", "HTTPS")
Rel(admin, cloudhelm, "Administra", "HTTPS")
Rel(cloudhelm, github, "Autentica via OAuth")
Rel(cloudhelm, catalogs, "Sincroniza e consulta preços")
Rel(cloudhelm, llm, "Solicita briefing quando habilitado")
Rel(cloudhelm, database, "Lê e grava dados", "SQL/TLS")
Rel(frontendHosting, user, "Entrega frontend", "HTTPS")
Rel(apiHosting, cloudhelm, "Executa API")
SHOW_LEGEND()
@enduml
```

## Nível 2 — Contêineres

```plantuml
@startuml CloudHelm-Containers
!include https://raw.githubusercontent.com/plantuml-stdlib/C4-PlantUML/master/C4_Container.puml
LAYOUT_WITH_LEGEND()

Person(user, "Usuário")
Person(admin, "Administrador")
System_Ext(github, "GitHub OAuth")
System_Ext(catalogs, "APIs de catálogo cloud")
System_Ext(llm, "OpenAI / Gemini")

System_Boundary(system, "CloudHelm") {
  Container(frontend, "Frontend estático", "HTML, CSS, JavaScript", "Interface, sessão JWT e chamadas REST")
  Container(api, "API Backend", "Python / FastAPI", "Auth, demandas, catálogo, pricing e backoffice")
  ContainerDb(db, "Banco de dados", "Supabase Postgres", "Usuários, demandas, catálogo, configurações e auditoria")
}

Rel(user, frontend, "Interage", "HTTPS")
Rel(admin, frontend, "Administra", "HTTPS")
Rel(frontend, api, "Consome API", "REST/JSON")
Rel(api, db, "Persiste e consulta", "SQLAlchemy / psycopg")
Rel(api, github, "OAuth")
Rel(api, catalogs, "Consulta preços")
Rel(api, llm, "Gera briefing opcional")
SHOW_LEGEND()
@enduml
```

## Nível 3 — Componentes do backend

```plantuml
@startuml CloudHelm-Components
!include https://raw.githubusercontent.com/plantuml-stdlib/C4-PlantUML/master/C4_Component.puml
LAYOUT_WITH_LEGEND()

Container_Ext(frontend, "Frontend estático", "HTML/JS")
ContainerDb_Ext(db, "Supabase Postgres", "Postgres")
System_Ext(github, "GitHub OAuth")
System_Ext(catalogs, "Catálogos cloud")
System_Ext(llm, "OpenAI / Gemini")

Container_Boundary(api, "API FastAPI") {
  Component(routes, "API Routers", "FastAPI", "Expõem contratos HTTP sob /api")
  Component(auth, "Auth e Security", "JWT/OAuth", "Autenticação, autorização e dependências")
  Component(demands, "Demand Service", "Serviço de domínio", "Cria demandas e dispara orquestração/transcrição")
  Component(orchestrator, "Orchestration Service", "Serviço de domínio", "Ranking, arquitetura e Terraform sugerido")
  Component(pricing, "Pricing Service", "Serviço de domínio", "Estimativa por componentes e fallback de preços")
  Component(catalog, "Cloud Catalog Service", "Integração", "Normaliza e persiste preços por provedor")
  Component(repositories, "Repositories", "SQLAlchemy", "Acesso a usuários, demandas, catálogo e configurações")
  Component(llmService, "LLM Service", "HTTP/OpenAI SDK", "Briefing opcional com fallback determinístico")
}

Rel(frontend, routes, "REST/JSON")
Rel(routes, auth, "Valida sessão")
Rel(routes, demands, "Encaminha demandas")
Rel(routes, pricing, "Solicita estimativa")
Rel(routes, catalog, "Sincroniza/consulta catálogo")
Rel(demands, orchestrator, "Orquestra demanda")
Rel(orchestrator, pricing, "Calcula custos")
Rel(orchestrator, catalog, "Usa catálogo")
Rel(orchestrator, llmService, "Solicita briefing")
Rel(catalog, catalogs, "Consulta APIs")
Rel(llmService, llm, "Prompt")
Rel(auth, github, "OAuth")
Rel(auth, repositories, "Usuários")
Rel(demands, repositories, "Demandas")
Rel(catalog, repositories, "Itens")
Rel(repositories, db, "SQL")
@enduml
```
