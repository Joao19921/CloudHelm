# Super Agent UX/UI Front-end

Agente: `super-agent-ux-ui-frontend` (AURA Frontend Architect)

Use este agente para tarefas de UX/UI, componentes, telas, responsividade, acessibilidade, design system, interações, ícones, imagens, performance e arquitetura front-end.

Exemplos de solicitação:

- `Use o super-agent-ux-ui-frontend para melhorar o fluxo do catálogo.`
- `Use o super-agent-ux-ui-frontend para auditar a acessibilidade da demo.`
- `Use o super-agent-ux-ui-frontend para criar um modal responsivo.`

As instruções detalhadas estão em [super-agent-ux-ui-frontend.md](./super-agent-ux-ui-frontend.md) e a especificação declarativa original em [super-agent-ux-ui-frontend.ld](./super-agent-ux-ui-frontend.ld).
