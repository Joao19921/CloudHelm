# Cloud service icons

The AWS, Azure and Google Cloud service icons in this directory are local copies selected from the providers' official architecture icon packages:

- AWS: AWS Architecture Icons, https://aws.amazon.com/architecture/icons/
- Azure: Azure Architecture Icons, https://learn.microsoft.com/en-us/azure/architecture/icons/
- Google Cloud: Google Cloud product icons, https://cloud.google.com/icons

OCI publishes an official architecture toolkit for draw.io rather than standalone SVGs. The local `oci.svg` is a compact provider marker used as a UI fallback; OCI service names remain shown beside it. Official toolkit: https://docs.oracle.com/en-us/iaas/Content/General/Reference/graphicsfordiagrams.htm
